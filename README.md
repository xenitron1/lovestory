# Couple Arcade

Небольшой статический сайт с играми для двоих.

## Игры

- «На одной волне» — выбираете один из двух вариантов и считаете совпадения.
- «Кто из нас?» — голосуете, к кому больше относится забавное утверждение.
- «Дуэль реакции» — 5 раундов на скорость реакции.
- «Секретный ответ» — оба отвечают на вопрос, ответы раскрываются одновременно.
- В лобби есть мини-чат.

## Как соединиться на расстоянии

1. Первый игрок вводит имя и нажимает «Создать игру».
2. Он копирует длинный код и отправляет второму игроку в мессенджере.
3. Второй игрок вводит имя, нажимает «Подключиться», вставляет код и получает ответный код.
4. Второй отправляет ответный код первому.
5. Первый вставляет ответ и нажимает «Подключиться».
6. После установления прямого WebRTC-соединения оба попадут в лобби.

## Важно

Соединение идёт напрямую через WebRTC. На большинстве домашних/мобильных сетей этого достаточно. В очень строгих корпоративных сетях или некоторых VPN P2P-соединение может блокироваться, потому что здесь намеренно нет отдельного TURN-сервера.
