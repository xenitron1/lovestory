# DUO — игры для двоих

Статический сайт для двух игроков: один может играть с ПК, второй — с iPad/телефона. Отдельный сервер приложения не нужен: после обмена кодами браузеры соединяются напрямую через WebRTC.

## Что внутри

1. На одной волне — совпадения в выборе.
2. Кто из нас? — голосование друг за друга.
3. Реакция — дуэль на скорость в миллисекундах.
4. Камень · ножницы · бумага — первый до 5 побед.
5. Красный или зелёный? — оценка ситуаций в отношениях.
6. Что бы ты выбрал? — парные дилеммы.
7. Рейтинг свиданий — оценка идей от 1 до 5.
8. Секретный ответ — ответы открываются одновременно.
9. Ответ за 5 секунд — быстрый блиц.
10. Правда или вызов — мягкая парная версия без жёстких заданий.

Плюс мини-чат, демо-режим, адаптивный интерфейс, анимированный фон, эффекты карточек, искры и конфетти.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите `index.html`, `styles.css`, `app.js` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Сохраните настройки и откройте выданную GitHub Pages ссылку.

Можно также использовать версию из папки `couple-arcade-one-file`: там весь проект находится в одном `index.html`.

## Как подключиться вдвоём

1. Первый игрок вводит имя и нажимает **Создать игру**.
2. Отправляет полученный длинный код второму игроку любым мессенджером.
3. Второй игрок вводит имя, нажимает **Подключиться**, вставляет код и создаёт ответный код.
4. Отправляет ответный код первому игроку.
5. Первый вставляет его у себя — после установления соединения откроется общее лобби.

> Примечание: WebRTC без собственного TURN-сервера работает в большинстве обычных сетей, но в некоторых корпоративных/строго NAT-сетях прямое соединение может не установиться.
